# student_task_tracker
Student_task_tracker repository for software engineering 2. 
Implements basic task management features (CRUD) using HTML, CSS, JS, PHP.

This project is a simple prototype of a Student Task Tracker system that allows users to add, edit, delete, and mark academic tasks as complete.
It is designed to run locally using XAMPP for demonstration purposes.

How to run:
1. Open the project folder and navigate to:
  student_task_tracker/database
2. Import the included SQL file (student_task_tracker.sql) into phpMyAdmin.
3. move the entire project folder to:
  C:/xampp/htdocs/
4. Start Apache and MySQL from the XAMPP Control Panel
5. Access the project in your browset at:
   http://localhost/student_task_tracker/
